# Portfólio — João Vitor Guilhermino Pinto

Repositório do meu portfólio profissional, criado com HTML, CSS e JavaScript. O arquivo contém o estilo, as interações e a imagem do retrato embutidos; não precisa de bibliotecas ou servidor para ser aberto localmente.

## Conteúdo

- portfolio-joao-vitor.html — página completa do portfólio.

## Visualizar no computador

1. Baixe ou clone este repositório.
2. Abra portfolio-joao-vitor.html no navegador.

O projeto não precisa de instalação nem de configuração de backend.

## Publicar como site no GitHub Pages

O GitHub Pages não está ativado neste repositório. Para publicar o site futuramente, renomeie o arquivo para index.html e, em Settings → Pages, escolha Deploy from a branch, a branch main e a pasta raiz (root). O endereço previsto será https://guilherminojv.github.io/portfolio-joao-vitor/.

## Regras do repositório

- Mantenha a branch principal em um estado que represente a versão atual do portfólio.
- Use mensagens de commit curtas e descritivas, em português ou inglês.
- Não envie senhas, tokens, chaves de API nem dados privados de alunos ou clientes.
- O HTML contém dados profissionais de contato e um retrato; revise esses dados antes de qualquer alteração de visibilidade ou republicação.
- O GitHub Pages deve permanecer desativado até que a publicação do site seja desejada.

O arquivo .gitignore exclui arquivos temporários comuns do macOS e do Windows.
